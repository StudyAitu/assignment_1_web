Project Description
This repository contains the solutions for Assignment #1 on web development basics. The project demonstrates fundamental skills in HTML5 and CSS3, including the creation of semantic structures, element positioning, and styling for tables and forms. All pages are connected by a common navigation bar, allowing users to easily switch between individual tasks.

Project Structure & Tasks
The following pages were implemented as part of this assignment:
index.html (Main Hub): The main landing page containing navigation to all completed tasks and a brief project overview.
task1.html (Task 1: Introduction to HTML & CSS): A personal webpage featuring text content, ordered and unordered lists, links, and a styled profile card with an image.  
task2.html (Task 2: Simple Webpage Layout): A classic two-column layout (Header, Navigation, Sidebar, Main content, Footer) built strictly using block <div> elements and CSS float positioning without Flexbox or Grid.  
task3.html (Task 3: Tribute Page): A tribute page dedicated to Alan Turing. It includes structured text, lists of important life events and achievements, an image, a styled link button to Wikipedia, and custom Google Fonts.  
task4.html (Task 4: CSS Table and Form): Contains a styled student grades table utilizing cell merging (rowspan), alternating row colors (nth-child), and specific row highlighting. The page also features a centered, interactive feedback form with various input types (text, email, select, radio, textarea).  
(Note: Task 5, which involves wireframing the Midterm Project in Figma, is a separate design task and is not included in this HTML/CSS codebase).  
Technologies Used
HTML5: Semantic markup (<header>, <nav>, <main>, <footer>, <aside>, <table>, <form>).  
CSS3: Linked via an external style.css file. Includes tag, class, and ID selectors, text styling, box model properties (margin/padding), borders, shadows (box-shadow), and block positioning (float).
