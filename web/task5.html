Midterm Project: Developer Portfolio Website

Topic Description: A professional Developer Portfolio website designed to showcase personal software engineering projects, technical stack expertise, and academic achievements at Astana IT University. The platform serves as an interactive online resume to present coding skills in Java, Python, and web technologies to potential employers and tech recruiters.

Target Users

  • Recruiters & HR Managers: Looking for software engineering talent and reviewing contact info.
  • Tech Leads & Hiring Managers: Evaluating technical skills, clean code standards, and project architectures.
  • Peer Developers: Exploring collaborative open-source repositories and shared solutions.

Website Structure & Sitemap (5 Pages)

  1. index.html: Home page featuring a hero introduction and quick summary.
  2. about.html: Background story, university education details, and core technical skills.
  3. projects.html: Detailed showcase of software development projects and GitHub links.
  4. resume.html: Professional CV layout, certificates, and technical stack breakdown.
  5. contact.html: Direct feedback form, email links, and social media profiles.
